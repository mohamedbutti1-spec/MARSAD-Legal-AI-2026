MARSAD UX SIMPLIFICATION PASS
No new features. This pass focuses entirely on user experience,
clarity, discoverability, and reducing cognitive load.

GOAL:
A first-time government user must be able to reach any desired
result within 3 clicks maximum.

═══════════════════════════════
1) SIDEBAR SIMPLIFICATION
═══════════════════════════════

Keep ONLY:

1. الخدمة الإرشادية
2. التأهيل والتدريب
3. الوضع التنفيذي
4. مكتبي

Remove duplicate or hidden navigation paths.

═══════════════════════════════

═══════════════════════════════

البحث القانوني الذكي

- تشريعي
- قضائي
- فقهي
- مقارن
- ذكاء اصطناعي

ai-search
kb-search
naip-search
assistant-search
research-search

═══════════════════════════════

- طالب

- وكيل نيابة
- قاضٍ
- محامٍ
- مستشار
- مشرع

═══════════════════════════════

═══════════════════════════════

- بحث سريع

Large buttons.
